TrainingModelUsingKeras
Project Overview

This project is a practical exercise (TP) focused on training a neural network using Keras and the Fashion MNIST dataset.

The objective is to build, train, and evaluate a deep learning model capable of classifying clothing images into 10 different categories.

Model Architecture

The neural network consists of 5 layers:

Input Layer: Reshapes the input data from 784 features (28 × 28 pixels) into a 28 × 28 image.
Hidden Layer 1: First hidden layer.
Hidden Layer 2: Second hidden layer.
Hidden Layer 3: Third hidden layer.
Output Layer: Predicts one of the 10 Fashion MNIST classes.
Dataset

Fashion MNIST – A dataset of 28 × 28 grayscale images representing 10 categories of clothing and fashion items.
