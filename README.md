📌 Project Overview

This project is a practical exercise (TP) focused on building, training, and evaluating a Neural Network using Keras on the Fashion MNIST dataset.

The main objective is to develop a deep learning model capable of classifying fashion images into 10 different categories.

🧠 Model Architecture

The neural network is composed of 5 layers:

Input Layer: Reshapes the input data from 784 features into a 28 × 28 image.
Hidden Layer 1: First hidden layer responsible for learning image features.
Hidden Layer 2: Second hidden layer for feature extraction.
Hidden Layer 3: Third hidden layer for further learning and classification.
Output Layer: Produces predictions across the 10 Fashion MNIST categories.
📊 Dataset – Fashion MNIST

The Fashion MNIST dataset consists of 70,000 grayscale images (28 × 28 pixels), divided into:

60,000 training images.
10,000 testing images.
10 different fashion categories.
